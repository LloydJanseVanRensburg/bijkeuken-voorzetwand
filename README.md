# Bijkeuken voorzetwand

Build plan for an insulated 44×94 stud wall with 18 mm OSB in the bijkeuken: frame and OSB layout to scale, Hornbach cut lists, shopping list, connection details and step-by-step build guide.

- `index.html`: the plan (served by GitHub Pages)
- `zaagplan.pdf`: printable version of the same plan
- `prep.html`: get-ready checklist and drill map for marking and drilling
