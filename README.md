# Bijkeuken build journal

Photo journal and build plans for the bijkeuken: an insulated stud wall, then a fridge cupboard and laundry corner. Served by GitHub Pages.

- `index.html`: home: the journey, with photos per part and links to the plans

**Part 1 · Stud wall**
- `wall.html`: plan and cut list: frame and OSB layout to scale, Hornbach cut lists, shopping list, connection details, step-by-step build
- `zaagplan.pdf`: printable version of the plan
- `prep.html`: get-ready checklist and drill map
- `brackets.html`: where every 90° bracket goes and how each joint is fitted
- `pipes.html`: how the frame clears the water pipe along the floor

**Part 2 · Laundry corner**
- `cupboard.html`: sketch of the fridge cupboard, worktop and wall strips
